# dotnet — til va framework chuqurligi

**Qachon:** 2-hafta (hozir emas — `dsa/` dan boshlang)

Bitta `DotNetLab.slnx` bo'ladi, 20 ta alohida loyiha emas. Har bir mavzu uchun
bitta loyiha + **uning test loyihasi**.

## Mavzular va real interview savollari

| Mavzu | Menga beriladigan savol |
|---|---|
| async/await ichkarisi | "`async void` nega yomon? Sync-over-async qanday deadlock beradi?" |
| `ConfigureAwait` | "ASP.NET Core'da kerakmi? Nega?" |
| GC | "Memory leak .NET'da qanday bo'ladi, GC bo'la turib?" |
| DI lifetimes | "Singleton ichiga Scoped inject qilsangiz nima bo'ladi?" ⭐ juda ko'p beriladi |
| LINQ deferred execution | "`IQueryable` va `IEnumerable` farqi — qachon SQL'ga tarjima bo'ladi?" |
| EF Core pitfalls | "N+1 nima, qanday topasiz, qanday tuzatasiz?" |
| EF Core tracking | "`AsNoTracking` qachon kerak, qachon zarar?" |

Har birini **kod bilan isbotlang** — gapirib emas, ishlatib ko'rsating.
